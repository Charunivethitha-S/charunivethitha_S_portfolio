# Charunivethitha Portfolio

## Deploy with GitHub + Vercel (no database/storage)
1. Extract this ZIP.
2. Open the extracted folder.
3. Select EVERYTHING inside it and drag it to GitHub -> Add file -> Upload files.
4. Commit the files.
5. Import this repository into Vercel.
6. Keep Root Directory as `.`.
7. Deploy.

The repository root must directly contain `app`, `components`, `lib`, `public`, `package.json`, `next.config.mjs`, `tsconfig.json`, and `jsconfig.json`.

## Editing later
Most portfolio content is in `lib/content.ts`. Edit projects, certificates, events, achievements, publications and skills there.

Images can be uploaded in GitHub to `public/images/projects`, `public/images/certificates`, and `public/images/events`. Videos should use external links such as YouTube rather than repository storage.

Replace placeholder email/social links in `app/page.tsx`.
